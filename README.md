# Next SNES Controller Tool

A simple tool for configuring SNES-compatible USB controllers: remap buttons, load firmware, and manage .lpl config files.

## Download

Go to [Releases](../../releases), download `NextSNESControllerTool.exe`, and run it. No installation required.

## Usage

1. Connect your controller.
2. Launch the app.
3. Paste a .lpl URL and click Load Config.
4. Click Download to fetch firmware.
5. Click Apply to send settings to the controller.
